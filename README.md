# TIL (Today I Learned)

삼성 청년 SW·AI 아카데미(SSAFY)에서 배운 내용을 매일 정리한 저장소입니다. 코딩 기초부터 데이터 분석, 데이터 엔지니어링, AI까지 학습 과정에서 다룬 개념과 실습 코드를 분야별로 기록합니다.

## 목적

- 학습한 내용을 기록하며 복습하고 정리
- 실습 코드와 개념 설명을 함께 남겨 추후 참고 자료로 활용
